# Icons

Generate these two PNG files for full PWA support:

- `icon-192.png` — 192×192px
- `icon-512.png` — 512×512px

You can use the `favicon.svg` as the source. Tools:
- https://realfavicongenerator.net
- https://maskable.app (for maskable icon)
- Or run: `npx pwa-asset-generator public/favicon.svg public/icons`
